Schema — sem-reveal

Contract per conventions.md v0.5. BDD source of truth for test/e2e/sem-reveal.cy.js. Changes here precede spec changes precede code. This document renders spec/schema/sem-reveal.md; the Markdown file remains the editing source.

A progressive disclosure block: teaser first, body hidden until the reader reveals it. The reader-chrome complement of sem-note's collapsed form, for body-size content.

Authoring form

<sem-reveal summary="Show the derivation" collapsed>
  <p>The derivation…</p>
</sem-reveal>

Class-form alias (conventions Appendix A): div.sem-reveal[data-summary], same collapsed attribute.

  • summary (optional): the teaser label; defaults to a generic "Show more" label localized by the theme.
  • collapsed: boolean attr — start hidden. Without it the block renders open (the reveal control collapses it).
  • Body is the element's content; any inline or block content is legal.

Rendered form

  • Fallback: teaser row with a disclosure control; body hidden/shown via the tier marker.
  • Upgraded: same DOM; smooth open/close animation.
  • JS-off: body readable (hide rule gated on tier markers); the teaser reads as a plain paragraph.
  • Print: bodies expand.
  • Deep links: the resolver opens a reveal whose body contains the hash target.

Events

  • sem-reveal-toggle, cancelable — before the body opens/closes.

A11y contract

  • The control is a button with aria-expanded; the body is its controlled region.
  • The teaser text is the accessible name.

Machine contract

  • One record; fields.summary when present; prose text = the body, read regardless of open/closed state.
  • collapsed is presentation state — never extracted; the invariant holds across toggling.
