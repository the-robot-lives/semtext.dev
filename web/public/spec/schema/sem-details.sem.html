Schema — sem-details / sem-detail / highlight

Contract per conventions.md v0.5. BDD source of truth for test/e2e/sem-details.cy.js. Changes here precede spec changes precede code. This document renders spec/schema/sem-details.md; the Markdown file remains the editing source.

Three related pieces: a set of collapsible entries (sem-details / sem-detail), and an inline highlight with an optional occluded form. Disclosure state is presentation; extraction reads it all.

Authoring form

<sem-details>
  <sem-detail summary="First">body</sem-detail>
  <sem-detail summary="Second">body</sem-detail>
</sem-details>

<p>The <highlight>key term</highlight> matters.</p>
<p><highlight>occluded<occluded>hidden full form</occluded></highlight></p>

Class-form alias (conventions Appendix A): div.sem-details › div.sem-detail with data-summary; span.sem-highlight with .sem-occluded for the occluded form.

  • sem-detail: summary attribute = collapsed label; body is the element's content.
  • highlight: inline; occluded child = the full form shown on interaction.
  • Global attrs (id, kind, tags, audience) apply to entries and highlights alike.

Rendered form

  • Fallback: sem-details renders entries with disclosure markers; each entry body hides/shows via the tier marker; occluded highlight shows the base form and reveals the occluded one on hover/focus/click.
  • Upgraded: same DOM; per-entry state; the occluded form animates open.
  • JS-off: all bodies and occluded forms readable inline (hide rules gated on tier markers).
  • Print: everything expands (all bodies + occluded forms visible).

Events

  • sem-detail-toggle, cancelable — before an entry opens/closes.

A11y contract

  • Entries use native <details>/<summary> semantics (authored or applied on upgrade).
  • Occluded highlight keeps both forms in the accessibility tree; the occluded form is announced as supplementary, not hidden.

Machine contract

  • Each sem-detail mints a record: fields.summary + prose text.
  • highlight mints a record with its base text; when an occluded child exists, fields.occluded carries the full form. Disclosure state never changes a record.
