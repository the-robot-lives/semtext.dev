Schema — sem-md

Contract per conventions.md v0.5. BDD source of truth for test/e2e/sem-md.cy.js. Changes here precede spec changes precede code. This document renders spec/schema/sem-md.md; the Markdown file remains the editing source.

Markdown rendered in place, with a toggle between the rendered view and the raw source. Unlike the rest of the vocabulary it takes Markdown text content, not HTML.

Authoring form

<sem-md label="Release notes" view-as="rendered" controls="toggle">
## Heading

- item one
- item two
</sem-md>

Class-form alias (conventions Appendix A): div.sem-md[data-label][data-view-as][data-controls] › Markdown text.

  • label (optional): accessible name / header label.
  • view-as: rendered (default) | raw.
  • controls: toggle — switch between views.
  • The Markdown source is preserved verbatim in the DOM (in a hidden template/attribute-equivalent node), so the raw view needs no re-fetch.

Rendered form

  • Fallback: renders the Markdown with the bundled minimal renderer (headings, lists, emphasis, links, fenced code, tables — no raw HTML passthrough, sanitization default-deny); the toggle flips to a <pre> of the raw source. Tables are real <table> elements with <thead>, <th scope="col"> and <tbody>; links get target="_blank" + rel="noopener".
  • Upgraded: same DOM contract; the same renderer by default.
  • JS-off: the raw source is readable; the rendered view appears on first run.

Events

  • sem-view-toggle (shared with sem-source), cancelable — before the view flips; detail carries the target view.

A11y contract

  • The toggle is a button with an accessible name (the label when present).
  • Rendered output uses real headings/lists/tables — not images of text, not aria-label summaries.

Machine contract

  • One record; text is the raw Markdown source, not the rendered prose; fields.label when present.
  • view-as never extracted (extraction §5c) — rendered and raw yield the same record.
