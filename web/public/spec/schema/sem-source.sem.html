Schema — sem-source

Contract per conventions.md v0.5. BDD source of truth for test/e2e/sem-source.cy.js (which also proves the cross-form extraction equality). Changes here precede spec changes precede code. This document renders spec/schema/sem-source.md; the Markdown file remains the editing source.

A transparent wrapper: it renders its children — real HTML, not a copy — with an optional toggle to view the markup source. It adds a view; it mints nothing and hides nothing.

Authoring form

<sem-source label="Live example" view-as="html" controls="toggle">
  <sem-note variant="tip">Renders in place.</sem-note>
</sem-source>

Class-form alias (conventions Appendix A): div.sem-source[data-label][data-view-as] › any content.

  • label (optional): header label for the example frame.
  • view-as: html (default) | source — the source view shows the children's serialized markup.
  • controls: toggle.
  • Transparent: any content is legal, exactly as if the wrapper were absent — children remain live vocabulary (nested sem-* elements upgrade normally, events propagate). The source view is generated from the DOM at toggle time; the author never maintains a second copy of the markup.

Rendered form

  • Fallback: a framed region (label header + toggle); view-as="source" swaps the frame's body for a <pre><code class="language-html"> serialization of the children — from the DOM, so docs never maintain a stale copy.
  • Upgraded: same contract; children keep upgrading inside the frame.
  • JS-off: children render normally; no frame chrome beyond CSS.

Events

  • sem-view-toggle (shared with sem-md), cancelable — before the view flips; detail carries the target view.

A11y contract

  • The frame is a region with an accessible name from label; the toggle is a button.
  • Children inside the frame keep their native roles and semantics; nothing is iframed.

Machine contract

  • Mints no records. The children extract as themselves, in document order, exactly as if the wrapper were absent — an invariant the extraction contract states and the cross-form test asserts: identical records from the tag form and the class form, and with the wrapper present or absent.
  • view-as never extracted (extraction §5c) — html and source views yield identical records.
