Schema — sem-note

Contract per conventions.md v0.5. BDD source of truth for test/e2e/sem-note.cy.js. Changes here precede spec changes precede code. This document renders spec/schema/sem-note.md; the Markdown file remains the editing source.

Authoring form

<sem-note variant="warning">body HTML</sem-note>
<sem-note variant="tip" collapsed>body HTML</sem-note>

Class-form alias (conventions Appendix A): div.sem-note[data-variant] › div.sem-note-body, same collapsed attribute. In the tag form the body is the element's own content; the tier that hides a collapsed body wraps it in .sem-note-body first.

  • variant: info (default) | warning | tip | danger.
  • collapsed: boolean attr — the body is hidden behind a ten-word teaser (.sem-note-summary) that expands on click.
  • view-as="margin": presentation only. On wide viewports the note floats right beside the prose that follows it (width --sem-margin-width, default 14rem), inside the container; a document whose column has a gutter pushes it out with --sem-margin-offset. On narrow viewports and in print it reads inline as an ordinary callout. CSS-only — no handler, no chrome, no record change.
  • id, kind, tags per global attribute catalog.
  • [hint | reveal] notation: this element hosts the first definition of the agent-instruction notation (conventions §3) — parse in v1 only if the fallback handler ships it for free; otherwise defer.
Unresolved condition: whether the [hint | reveal] notation parses in v1 depends on the fallback handler shipping it for free; otherwise it is deferred.

Rendered form

  • Upgraded: <sem-note> itself (Lit SemNote — minimal: variant icon, collapsed behavior). No shadow root; light DOM, content searchable.
  • Pre-upgrade / JS-off: :is(sem-note, .sem-note) base in semtext.css — accent border + variant label via attribute selectors, both authoring forms from one rule (D10). The collapsed-body hide rule is gated on a tier marker, so JS-off the body is readable.
  • view-as="margin": float: right at min-width: 64rem, right margin --sem-margin-offset (0 by default, negative to reach a gutter); inline otherwise and under @media print.
  • role="note": component sets on upgrade; docs author it pre-set so machine readers see the role without JS.

Events

None.

A11y contract

  • role="note" present in DOM (authored or set on upgrade).
  • Variant by accent + the variant attribute; no aria-live.
  • Collapsed form: the teaser is a click target; the deep-link resolver opens it for a hash inside.

Machine contract

  • variant + kind read as qualified annotation; statement content is the assertion text.
  • view-as is never extracted (extraction §5c): a margin note and an inline note yield the same record.
