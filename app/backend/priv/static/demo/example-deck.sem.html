try-deck · four facts

The document every view on the landing page reads: authored once, opened here, paged in a shell, rendered as plain text for agents. Switching views rewrites nothing. view-as is a parameter, not an identity A fact is a fact in every view; the attribute only selects a rendering. Each view is a different element type. Components render into light DOM Content stays in the page, so find-in-page, copy and plain CSS all still reach it. Content moves into a shadow root for encapsulation. Extraction reads the authored document Generated chrome is skipped, so records do not depend on the view on screen. Extraction reads whatever is currently rendered. Authoring needs no build step One stylesheet and one script tag in a plain HTML file; a theme is optional. A bundler compiles the vocabulary down to HTML.
