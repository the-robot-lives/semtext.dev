Screen 10 — code card

*Current since v0.7.0.* sem-code draws a dedicated card: the badge names lang and provenance (`lang · file`), a dim line-number gutter runs down the left, and lines keep their column layout (never reflowed). `controls="wrap"` gives ↪ continuations; without it long lines cut with … at the frame edge; `mark="2,4-5"` carries a ▌ gutter marker and bold; entities decode (`<` renders as a literal <). Keywords tint blue, strings green, comments dim — tints not visible in a monospace mock.

Screen 11 — table grids

*Current since v0.7.0.* sem-table draws a heavy box-drawn grid: the caption is the header badge, columns size to their content (emoji count two cells), header rows bold, alignment from the delimiter row (numeric columns right-align when unauthored), cell wrap grows the row (an authored br is a hard in-cell break), and counted footers report hidden rows and columns.
