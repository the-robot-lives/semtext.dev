# US-504: Adopter Gallery

## User Story

**As a** content platform owner
**I want to** see who else uses SemText, with the site itself listed as entry #1
**So that** I can judge adoption by evidence instead of claims.

## Acceptance Criteria

- **Given** the landing page
  **When** the adopter section renders
  **Then** semtext.dev's own dogfooded document set is entry #1 (honest self-reference,
  per the briefing note that dogfooding is a live document set).
- **Given** an external adopter
  **When** they are added
  **Then** each entry links a real, rendered document — not a logo wall.

## Notes

Social proof grows as W4/W5 land; the section is cheap to add now and honest even with
one entry.
